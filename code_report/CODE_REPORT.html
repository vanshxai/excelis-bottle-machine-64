Faulter / Yanthros code report

1. All code locations

One row per folder of code. Click a folder name to jump to its file-by-file report. “Exact copy” folders hold files that are byte-for-byte the same as another folder.

2. The same machine, rebuilt again and again

How many code files in each folder are about each machine (found by machine names in file paths and descriptions). A machine that shows up in several folders was rebuilt rather than reused.

3. File-by-file report

Click any file row to see its functions and classes (with line numbers), web routes, libraries, which files in the same folder it uses or is used by, and its full path. “What it does” is taken from the file's own docstring, leading comment or page title; where the file has none, the report says so and lists what the file defines instead.

4. Copies between folders

Files whose content is the same (exact) or mostly the same (near, by shared lines) as a file in an earlier folder in this report.

What this report leaves out

  • Generated code (per-part part_code.py files under bottle_machine_64/projects), app bundles and build output, virtual environments, node_modules.
  • Third-party libraries (three.js, OrbitControls, the BitNet repository, Node-RED defaults inside its own folders).
  • Data and notes: JSON, CSV, databases, markdown, PDFs, images, videos. They are not code, but several folders depend on them.
  • Files bigger than 3 MB, and anything in folders not listed in section 1. iCloud, other computers and devices were not scanned.

Built by reading the files' structure (nothing was run or changed). Descriptions come from the code's own words, so a file with no docstring is described only by what it defines.
